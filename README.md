# The Dungeon of Shadow and Light - A terminal-based dungeon crawler game

## How to play

### Prerequisites
* Python 3.8 or higher installed on your system.

### Running the game
* Clone the repository and run `main.py`.

```bash
python3 main.py
```

## Game features
* Loot: Discover many different weapons, armour pieces and potions.
* Dynamic Rooms: Experience different room types including Shops, Traps, Enemy encounters and more.
* Combat: Fight enemies in turn-based battles using your character's stats and items.
* ASCII Visuals: Retro terminal-based sprites and art.
* Story & Scenarios: Rich narrative interactions and event scenarios.
* Boss fight: Defeat the grueling boss at the end of the dungeon to win.

## Controls & Navigation

* Movement & Choices: Type the corresponding keyword and press `Enter`
* Exit: Press `Ctrl` + `C`
